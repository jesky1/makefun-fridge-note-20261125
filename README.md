One funny passive-aggressive note from a smart fridge to its owner, written by a small deterministic Node program for make.fun's "Notes From a Passive-Aggressive Fridge" bounty ($2 in USDC). The fridge kept count: 14 door openings, zero meals eaten — so it has demoted itself to a very cold night-light with trust issues.

## Run it

```sh
node main.ts
```

It validates the line (1–200 characters, one line, no trailing whitespace, no control or invisible characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Tests

```sh
node --test test.mjs
```
